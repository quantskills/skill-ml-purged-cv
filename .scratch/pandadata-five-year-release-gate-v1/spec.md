# PandaData five-year governed release gate v1

Status: resolved

## Execution prompt

Use only the existing local PandaData daily Parquet cache when it already covers a
trailing five-calendar-year window. Govern continuous-contract identity before
splitting, preserve a final 252-session untouched Holdout, rank a frozen model set on
chronological development regimes, compare Purged K-Fold/CPCV/causal Walk-Forward with
one fixed model, and persist only redacted evidence. Consume the Holdout at most once.

## Acceptance contract

- At least 5,000 observations, 252 sessions, and 20 assets remain in every structural
  training fold/combination.
- Every structural channel independently reports zero retained Information Interval
  overlaps.
- Ranking evidence uses identical candidates across at least three chronological
  development regimes.
- Final Holdout access is bound to a frozen protocol and append-only receipt.
- A reporting failure after receipt creation never authorizes Holdout reuse.
- Evidence separates leakage-control correctness from model value and profitability.

## Non-goals

- Downloading data when the local cache already satisfies the window.
- Persisting credentials, raw rows, targets, or Holdout predictions.
- Claiming remote CI, publication, profitability, deployment, or observation.
